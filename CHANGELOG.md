\# Changelog



Toutes les modifications importantes du projet sont listées ici.



\## \[1.0.0] - 2026-08-01



\### Ajouté

\- Packaging Python avec `pyproject.toml`

\- Commande installable `taskflow`

\- Installation locale avec `pip install .`

\- Script `setup.sh` d'installation automatisée

\- Système de logging avec `logging`

\- Configuration externe avec `config.ini`

\- Export CSV des tâches

\- API FastAPI



\### Tests

\- Tests unitaires validés avec pytest

\- Build du package validé avec `python -m build`
